# English Kids Quest — إنجليش كيدز كويست

> رفيق لعب للأطفال العرب من 5–9 سنوات لبناء نطق إنجليزي واثق عبر حروف وجمل يومية في خطوات قصيرة مرحة.

تطبيق ويب تفاعلي بتصميم «حكاية الورق الملوّن» — دفتر أنشطة رقمي دافئ يعتمد على لون **Emerald Leaf #147D6D**، بخطوط Baloo 2 وTajawal وNunito Sans، ومبني بواجهة عربية بالكامل.

## المميزات

- **صفحة الحروف:** 26 درسًا للحروف الإنجليزية مع الرمز الصوتي IPA، كلمة مثال، ترجمة عربية، ونطق تقريبي بالعربية.
- **صفحة الجمل:** أكثر من 50 جملة يومية مصنّفة (تحية، لباقة، بيت، مشاعر، لعب، تعلّم) مع بطاقة تدريب نطق لكل جملة.
- **وضع «قلها معي»:** تدريب نطق مباشر باستخدام التعرف على الصوت في المتصفح — يسمع الطفل الكلمة ثم يقولها ويحصل على نتيجة فورية (صح / حاول مرة أخرى) دون حفظ أي تسجيل.
- **ثلاث ألعاب تفاعلية:**
  - «اسمع واصطد» — اصطياد الحرف الصحيح بعد الاستماع.
  - «بيت الكلمة» — مطابقة كل كلمة ببيت الحرف الخاص بها.
  - «رتّب الحكاية» — ترتيب الجمل لتكوين حكاية صحيحة.
- **نظام النجوم والمكافآت:** احتفالات مرئية (نجوم طائرة، قصاصات، هالات) وأصوات نجاح مولّدة عبر Web Audio، مع احترام إعداد `prefers-reduced-motion`.
- **صفحة التقدم:** متابعة الحروف المكتملة والجمل المنتهية ونجوم الألعاب — كل شيء محفوظ محليًا على الجهاز.

## التقنيات

| الطبقة | التقنية |
|--------|---------|
| الواجهة | React 19 + TypeScript 5.6 |
| البناء | Vite 7 |
| التنسيق | Tailwind CSS 4 + مكونات shadcn/ui |
| التوجيه | wouter |
| الخادم (إنتاج) | Express 4 |
| الصوت | ملفات صوتية مضمّنة + Web Speech APIs (نطق وتعرّف على الكلام) |

## التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات (يفضل pnpm)
pnpm install

# 2) تشغيل خادم التطوير
pnpm dev
# التطبيق يعمل على http://localhost:3000

# 3) التحقق من الأنماط
pnpm check

# 4) بناء نسخة الإنتاج وتشغيلها
pnpm build
pnpm start
```

## الأصول المضمنة

- **الصوت:** 102 مقطع صوتي (26 حرفًا، 26 كلمة، 50 جملة) مولّدة بتقنية TTS ومخزنة محليًا في `client/public/audio/` — لا يحتاج التطبيق أي خدمة خارجية لتشغيل الصوت.
- **الصور:** رسوم توضيحية بأسلوب القصاصات الورقية في `client/public/img/`.

## هيكل المشروع

```
├── client/
│   ├── index.html
│   ├── public/
│   │   ├── audio/         # مقاطع صوتية محلية (حروف / كلمات / جمل)
│   │   └── img/           # رسوم توضيحية محلية
│   └── src/
│       ├── pages/         # LearningApp (الحروف/الجمل/الألعاب/التقدم) و Home
│       ├── components/    # مكونات shadcn/ui + ErrorBoundary
│       ├── lib/           # خريطة الصوت المحلي وأدوات مساعدة
│       └── index.css      # نظام التصميم (حكاية الورق الملوّن)
├── server/index.ts        # خادم Express لخدمة نسخة الإنتاج
├── shared/                # ثوابت مشتركة
└── vite.config.ts
```

> **ملاحظة:** وضع «قلها معي» يحتاج متصفحًا يدعم Web Speech Recognition (Chrome أو Edge حاليًا) وإذن ميكروفون. لا يُرسل أي صوت إلى أي خادم — المعالجة تحدث داخل المتصفح.
