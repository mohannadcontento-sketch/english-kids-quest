# English Kids Quest — إنجليش كيدز كويست

> رفيق لعب للأطفال العرب من 5–9 سنوات لبناء نطق إنجليزي واثق عبر حروف وجمل يومية في خطوات قصيرة مرحة.

تطبيق ويب تفاعلي بتصميم «حكاية الورق الملوّن» — دفتر أنشطة رقمي دافئ يعتمد على لون **Emerald Leaf #147D6D**، بخطوط Baloo 2 وTajawal وNunito Sans، ومبني بواجهة عربية بالكامل.

## المميزات

- **صفحة الحروف:** 26 درسًا للحروف الإنجليزية بأسلوب الفونيكس — يسمع الطفل **صوت الحرف نفسه** (/æ/، /b/، /k/...) مع الرمز IPA وكلمة مثال وترجمة عربية ونطق تقريبي بالعربية.
- **صفحة الجمل:** أكثر من 50 جملة يومية مصنّفة (تحية، لباقة، بيت، مشاعر، لعب، تعلّم) مع بطاقة تدريب نطق لكل جملة.
- **وضع «قلها معي» (تسجيل وتقييم):** الطفل يسمع ثم يسجل بصوته والتطبيق يقيّم فورًا: صح ✓ أو حاول مرة أخرى مع **نسبة مطابقة مئوية** وزر «اسمع صوتك» لسماع التسجيل — كل شيء داخل المتصفح ولا يُحفظ أي تسجيل في أي مكان.
- **ثلاث ألعاب تفاعلية:**
  - «اسمع واصطد» — اصطياد الحرف الصحيح بعد الاستماع.
  - «بيت الكلمة» — مطابقة كل كلمة ببيت الحرف الخاص بها.
  - «رتّب الحكاية» — ترتيب الجمل لتكوين حكاية صحيحة.
- **نظام النجوم والمكافآت:** احتفالات مرئية (نجوم طائرة، قصاصات، هالات) وأصوات نجاح مولّدة عبر Web Audio، مع احترام إعداد `prefers-reduced-motion`.
- **صفحة التقدم:** متابعة الحروف المكتملة والجمل المنتهية ونجوم الألعاب — كل شيء محفوظ محليًا على الجهاز.

## التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات (يفضل pnpm)
pnpm install

# 2) تشغيل خادم التطوير
pnpm dev
# التطبيق يعمل على http://localhost:3000

# 3) التحقق من الأنماط
pnpm check

# 4) بناء نسخة الإنتاج وتشغيلها
pnpm build
pnpm start
```

## الأصول المضمنة

- **الصوت:** 102 مقطع صوتي (26 حرفًا، 26 كلمة، 50 جملة) مخزنة محليًا في `client/public/audio/` — لا يحتاج التطبيق أي خدمة خارجية لتشغيل الصوت:
  - **الكلمات الـ26:** تسجيلات صوتية بشرية حقيقية من Wikimedia Commons (ملفات `En-us-*.ogg`).
  - **الحروف:** تسجيلات بشرية حقيقية لأصوات الفونيكس الصافية من FreeReading (CC BY-SA 3.0) — استُخرج مقطع الصوت الخالص من كل تسجيل «صوت + كلمة مثال» — تُعلّم صوت الحرف لا اسمه، بدون أي صوت AI.
  - **الجمل:** نفس الصوت الطفلي بسرعة أبطأ مناسبة للأطفال.
  - ملفات mp3 أحادية 64kbps مع تسوية موحّدة لمستوى الصوت (-16 LUFS) — التفاصيل الكاملة في `client/public/audio-sources.json`.
- **الصور:** رسوم توضيحية بأسلوب القصاصات الورقية في `client/public/img/` (مُحسَّنة للويب).
- **تقييم النطق (سلسلة محركات بالترتيب):** التطبيق يقيّم نطق الطفل بأفضل محرك متاح تلقائيًا:
  1. **المحرك الاحترافي المجاني — Whisper عبر Groq (مفتوح المصدر، بدون بطاقة):** موديل [Whisper large-v3-turbo](https://github.com/openai/whisper) مفتوح المصدر (رخصة MIT) مستضاف على طبقة Groq المجانية التي **لا تتطلب بطاقة ائتمان** — مفتاح مجاني من [console.groq.com/keys](https://console.groq.com/keys) يمنح 20 تقييمًا/دقيقة و2000/يوم (25 م.ب لكل ملف). صفر تنزيل على جهاز الطفل: التسجيل (~40KB) يُرسل إلى الدالة السحابية `api/assess.js` فتُحوَّل لنص ثم تُقيَّم بمطابقة مرنة (مفرّدات/جمع، أدوات تعريف، مسافة ليفنشتاين). يُفعَّل بإحدى طريقتين:
     - وضع الاستضافة على Vercel (الأفضل لكل الزوار): ضع المفتاح في متغير البيئة `GROQ_API_KEY` ثم Redeploy — المفتاح لا يراه أي زائر أبدًا.
     - وضع المفتاح الخاص: الأب/المعلم يُدخل مفتاح Groq من نافذة «محرك تقييم النطق» — يُخزَّن في متصفحه فقط ويُرسل مع كل طلب لهيدر `x-groq-key`.
  2. **محرك المتصفح المجاني (Web Speech API):** يعمل فورًا في كروم وإيدج وسفاري بدون أي إعداد، مع مطابقة مرنة (بدائل، مفرّدات/جمع، أدوات تعريف) وحد أدنى مضمون للاستماع وبدائل متعددة.
  3. **المحرك الذكي داخل الجهاز (اختياري):** مشروعان مفتوحان يعملان بالكامل داخل متصفح الطفل (الصوت لا يترك الجهاز):
     - [Transformers.js](https://github.com/huggingface/transformers.js) من Hugging Face (رخصة MIT).
     - موديل [Whisper tiny.en](https://huggingface.co/onnx-community/whisper-tiny.en) بصيغة ONNX (~45 م.ب تنزيل اختياري مرة واحدة ثم يعمل أوفلاين، رخصة MIT).
     - يُستخدم كمراجعة ثانية عند ضعف نتيجة المحرك الأول، وكمحرك أساسي في Firefox وiOS Safari — لا يُنزَّل أبدًا بدون موافقة صريحة (زر المحرك).
  4. **بديل متقدم — Microsoft Azure Pronunciation Assessment (يحتاج بطاقة عند التسجيل):** سكور دقة لكل فونيم (0-100) — يُفعَّل بمفتاح خاص من النافذة أو بمتغيرَي البيئة `AZURE_SPEECH_KEY` و`AZURE_SPEECH_REGION` عبر `api/speech-token.js`.
- التسجيلات من Wikimedia Commons وFreeReading تخضع لرخص المحتوى الحر الخاصة بها (CC BY-SA / CC0).

## هيكل المشروع

```
├── client/
│   ├── index.html
│   ├── public/
│   │   ├── audio/         # مقاطع صوتية محلية (حروف / كلمات / جمل)
│   │   └── img/           # رسوم توضيحية محلية
│   └── src/
│       ├── pages/         # LearningApp (الحروف/الجمل/الألعاب/التقدم) و Home
│       ├── components/    # مكونات shadcn/ui + ErrorBoundary
│       ├── lib/           # خريطة الصوت المحلي وأدوات مساعدة
│       └── index.css      # نظام التصميم (حكاية الورق الملوّن)
├── server/index.ts        # خادم Express لخدمة نسخة الإنتاج
├── shared/                # ثوابت مشتركة
└── vite.config.ts
```

> **ملاحظة:** وضع «قلها معي» يحتاج متصفحًا يدعم Web Speech Recognition (Chrome أو Edge حاليًا) وإذن ميكروفون. لا يُرسل أي صوت إلى أي خادم — المعالجة تحدث داخل المتصفح.
